# Практика 7 - Современные front-end фреймворки

## Темы: React, Angular, Vue

### Цель работы:
Ознакомиться с основными современными инструментами разработки пользовательских интерфейсов в вебе, понять, почему сегодня редко используют «чистый» JavaScript, и получить практический опыт запуска приложения на одном из популярных фронтенд-фреймворков.

### Краткая теоретическая справка
В ранние годы веб-разработки интерактивность на сайтах создавалась с помощью чистого JavaScript — то есть разработчики писали код напрямую для манипуляции DOM-элементами, обработки событий и обмена данными с сервером. Однако по мере роста сложности веб-приложений (например, почтовые клиенты, социальные сети, онлайн-редакторы) такой подход стал неэффективным: код быстро превращался в нечитаемый и трудно поддерживаемый «спагетти».

Для решения этих проблем появились фронтенд-фреймворки и библиотеки, которые:

структурируют код,
упрощают управление состоянием приложения,
автоматизируют обновление интерфейса при изменении данных,
поддерживают повторное использование компонентов.
Сегодня основными игроками на рынке фронтенд-разработки являются:

React (разработан Facebook/Meta) — не фреймворк в строгом смысле, а библиотека для построения пользовательских интерфейсов. React использует компонентный подход и виртуальный DOM для эффективного обновления интерфейса. Очень популярен благодаря гибкости и богатой экосистеме.
Angular (разработан Google) — полноценный фреймворк, включающий всё необходимое «из коробки»: маршрутизацию, управление состоянием, инструменты для тестирования и т.д. Использует TypeScript по умолчанию и подходит для крупных enterprise-приложений.
Vue.js — прогрессивный фреймворк, который легко интегрируется в существующие проекты и при этом масштабируется до уровня полноценного SPA (Single Page Application). Отличается простотой освоения и чёткой документацией.
Все три технологии решают одну и ту же задачу — упрощают создание сложных интерфейсов, но делают это разными способами и с разной философией.
