# Практика 6 - Реализация Фронтенда для приложения ToDoList

## Темы: HTML, CSS

В этом занятии применим знания из прошлых занятий для создания приложения ToDoList - списка задач. Ниже на изображении приведен дизайн приложения.

![ToDo](/lesson_6/images/image_todo.png "ToDo")

Для каждой задачи есть:
- Текст
- Статус (выполнено / не выполнено)

### Задание

Сверстать приложение ToDoList используя HTML и CSS. Для реализации можно использовать компоненты HTML: form, div, input, button и другие. 

По желанию можно использовать JavaScript, TypeScript и фронтенд фреймворки.
