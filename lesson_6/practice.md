# Практика 5 - Реализация API для приложения ToDoList

## Темы: Node.js, NestJS

В этом занятии применим знания из прошлых занятий для создания приложения ToDoList - списка задач. Ниже на изображении приведен дизайн приложения.

![ToDo](/lesson_6/images/image_todo.png "ToDo")

Для каждой задачи есть:
- Текст
- Статус (выполнено / не выполнено)

### Задание

Реализовать API с помощью NestJS. Для этого нужно реализовать следующие эндпоинты

1. Создание задачи
POST /api/tasks/

2. Отметить задачу выполненой
POST /api/tasks/{id}/finish

3. Отметить задачу невыполненой
POST /api/tasks/{id}/todo

4. Получить список задач
GET /api/tasks

Также в этом эндпоинте добавить опциональный (необязательный) параметр search, с помощью которого фильтруем задачи (Подсказка. У массивов в js есть метод .filter)

Также в этом списке должно выводиться количество выполненных и количество невыполненных задач. 


Использовать БД необязательно. Можно хранить задачи в памяти приложения (то есть, если приложение при перезапуске будет новые терять данные, то это будет считаться нормальным поведением).

### Требования к заданию
1. Каждый эндпоинт должен быть рабочим и выполнять свою функцию
2. В эндпоинтах, принимающих какие-либо входные данные, должна быть валидация входных данных
3. Для каждого эндпоинта должна быть описана документация через Swagger
